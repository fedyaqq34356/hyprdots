# Идеи

Список того, что можно добавить к этой системе. Ничего из уже сделанного здесь
нет — только то, чего пока не существует.

Уже реализовано и в списке не повторяется: волна в OSD с реальным спектром,
виджет системных колец на Super+F1, карточки уведомлений с таймером-обводкой и
синтезированными звуками, курсор из палитры, сортировщик Downloads, секундная
дуга у часов, след при переключении столов, тепловая карта коммитов в
календаре, плавный переход палитры, кольцо прогресса вокруг обложки, выезд
бара при старте, переработанные анимации Hyprland, OCR по Super+Shift+T.

Висит незакрытым: ребут ради `acpi_backlight=native`, автозапуск `hypridle`,
бэкапы, обратная синхронизация `hyprdots`.
