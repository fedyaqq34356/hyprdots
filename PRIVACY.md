# Приватность — 240 вещей

Ничего из `IDEAS.md` здесь не повторяется. Раздел «Безопасность и
приватность» там закрывает пункты 108–115, тут они не дублируются.

Порядок внутри разделов — от того, что делается за минуту, к тому, что
меняет модель угроз.

## Сеть: базовое (1–20)

1. `nftables` с дефолт-дропом исходящих и явным allow-листом портов.
2. Отдельная цепочка для правил, которые ставит контейнерный рантайм, чтобы он не открывал дыры молча.
3. Запрет IPv6, если провайдер его не даёт — иначе утечка мимо VPN.
4. Killswitch VPN: дроп всего, кроме интерфейса `wg0` и адреса эндпоинта.
5. Проверка killswitch скриптом: поднять, убить туннель, проверить, что трафика нет.
6. WireGuard вместо OpenVPN там, где можно — меньше метаданных в рукопожатии.
7. Свой WireGuard-сервер на VPS вместо чужого провайдера.
8. Разные туннели для разных задач: один для ботов, другой для браузера.
9. Маршрутизация по приложениям через `netns` вместо глобального VPN.
10. Отдельный network namespace для торрентов, без выхода в обход туннеля.
11. Рандомизация MAC при каждом подключении к Wi-Fi.
12. Запрет автоподключения к открытым сетям.
13. Забывать сети после недели неиспользования — список SSID это профиль перемещений.
14. Отключение Wi-Fi-сканирования в фоне, когда подключён по кабелю.
15. Отключение LLMNR, mDNS и NetBIOS-подобных широковещательных запросов.
16. Проверка, что `avahi` не слушает наружу, или его удаление.
17. Запрет исходящего SMTP и IRC-портов, если ими не пользуешься — ловушка для малвари.
18. Логирование новых исходящих соединений с уведомлением в бар.
19. `nftables`-счётчики по правилам и еженедельный отчёт, куда система ходила.
20. Отдельный VLAN или гостевая сеть для умных устройств, если роутер умеет.
